# AI Live Drowsiness Alert System

A real-time system that watches a person's face through a webcam, detects signs of drowsiness and fatigue using an AI facial-landmark model, and sounds an alarm before they fall asleep. Built for drivers, night-shift workers, students and anyone operating machinery.

## Features

| Feature | What it does |
|---|---|
| AI face landmarks | Google MediaPipe Face Landmarker tracks 468 points on the face in real time |
| Eye-closure alarm | Eyes closed for 1 second or more triggers a loud siren and a flashing red screen |
| Auto-calibration | Learns each user's normal open-eye size in the first 3 seconds, so it works for small or large eyes and with spectacles |
| Yawn detection | Mouth Aspect Ratio detects yawns and counts them |
| PERCLOS fatigue score | Percentage of time the eyes were closed over the last 60 seconds, the standard fatigue measure used in driver-safety research |
| Fatigue warning | PERCLOS above 15 % or 3 yawns within 5 minutes shows a "take a break" warning |
| Distraction check | Warns when the face is not visible for 3 seconds (looking away / head dropped) |
| Blink counter | Counts blinks and shows blinks per minute |
| Event log | Every alert, yawn and warning is saved to a CSV file with a timestamp |
| Snapshots | A picture is saved each time the drowsiness alarm fires |
| Night mode | `--enhance` brightens dark images with CLAHE |
| No extra files | The alarm sound is generated by code; the AI model downloads itself on first run |

## How it works

```
Webcam ──► MediaPipe Face Landmarker ──► Eye & mouth geometry ──► Decision rules ──► Alarm / HUD / Log
             (468 facial points)          EAR, MAR                closed-eye timer
                                                                  PERCLOS, yawns
```

**1. Eye Aspect Ratio (EAR).** Six points are taken around each eye: two corners (p1, p4) and two pairs on the upper and lower eyelids (p2–p6, p3–p5).

```
        |p2 − p6| + |p3 − p5|
EAR = ─────────────────────────
             2 × |p1 − p4|
```

When the eye is open EAR is about 0.25–0.35; when it closes, the eyelid distance shrinks and EAR drops towards 0.1. The average of both eyes is used, smoothed over 3 frames.

**2. Calibration.** For the first 3 seconds the system records the user's open-eye EAR and sets the threshold to 72 % of it (kept between 0.12 and 0.30). Hysteresis of 5 % stops the state flickering near the threshold.

**3. Mouth Aspect Ratio (MAR).** Average inner-lip opening divided by mouth width. MAR above 0.6 for at least 1 second is counted as a yawn. The eye-closure alarm is paused during a yawn, because eyes naturally squint while yawning.

**4. Decision rules.**

| Condition | Result |
|---|---|
| Eyes closed < 1 s | Counted as a normal blink |
| Eyes closed ≥ 1 s | **DROWSY** – alarm rings until the eyes open |
| PERCLOS ≥ 15 % (after 20 s of data) | **FATIGUE** warning |
| 3 yawns within 5 minutes | **FATIGUE** warning |
| No face for 3 s | **NO FACE** warning (alarm optional) |

## Tech stack

Python 3, OpenCV (camera capture and drawing), MediaPipe (AI face-landmark model), NumPy (geometry), pygame-ce (alarm sound; the community edition of Pygame, which supports the newest Python versions).

## Setup

You need Python 3.9 or newer and a webcam.

**Windows**
```
cd ai-drowsiness-alert
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux**
```
cd ai-drowsiness-alert
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Run

```
python drowsiness_alert.py
```

On the first run the face model (about 3.7 MB) is downloaded into `models/`. Look at the camera with your eyes normally open for 3 seconds while it calibrates, then the system starts monitoring.

**Options**

| Option | Default | Meaning |
|---|---|---|
| `--camera 1` | 0 | Use a different webcam |
| `--closed-seconds 1.5` | 1.0 | How long eyes must stay closed before the alarm |
| `--ear-threshold 0.21` | auto | Fixed threshold instead of calibration |
| `--mar-threshold 0.5` | 0.6 | Yawn sensitivity (lower = more sensitive) |
| `--alarm-on-no-face` | off | Also ring the alarm when the face disappears |
| `--enhance` | off | Low-light / night enhancement |
| `--no-sound` | off | Silent mode (visual alerts only) |
| `--no-snapshots` | off | Don't save alert pictures |

Example for a night drive: `python drowsiness_alert.py --enhance --alarm-on-no-face`

**Keyboard controls** (click the video window first): `q` or `Esc` quit, `c` recalibrate, `m` mute or unmute.

## Output

The screen shows live EAR, threshold, MAR, PERCLOS, blinks per minute, yawns, alert count and FPS, with eye outlines that turn red when closed and a progress bar that fills up as the eyes stay closed.

Each session writes `logs/session_YYYYMMDD_HHMMSS.csv`:

```
timestamp,event,ear,mar,perclos,details
2026-10-30T21:14:03,CALIBRATED,0.301,,,open-eye EAR 0.301 -> threshold 0.217
2026-10-30T21:16:40,YAWN,0.284,0.071,0.040,yawn #1
2026-10-30T21:18:12,DROWSY_ALERT,0.112,0.043,0.090,eyes closed 1.0s (alert #1)
2026-10-30T21:18:14,ALERT_CLEARED,0.262,0.040,0.110,alarm lasted 2.1s
```

Snapshots of each alarm are saved in `logs/snapshots_<session>/`.

## Demo script (for presentation / viva)

1. Start the program and let it calibrate; point out the EAR value and threshold.
2. Blink normally: the blink counter rises, no alarm.
3. Close your eyes for 1–2 seconds: the bar fills, the screen flashes red and the siren rings; open your eyes and it stops.
4. Yawn widely: "Yawn detected" appears and the yawn count rises.
5. Turn your face away for 3 seconds: "Face not detected" warning.
6. Quit with `q` and open the CSV log and snapshot folder.

## Troubleshooting

| Problem | Fix |
|---|---|
| `Could not open camera 0` | Close Zoom/Teams/browser tabs using the camera, or try `--camera 1` |
| Model download fails | Download `face_landmarker.task` from the URL printed in the terminal and place it in `models/` |
| Alarm fires too easily | Increase `--closed-seconds`, or press `c` to recalibrate with eyes fully open |
| Alarm doesn't fire | Recalibrate in good light, or set `--ear-threshold 0.23` |
| Dark room / night | Use `--enhance` and add a small light facing you; an IR camera works best |
| No sound | Check the system volume; the program falls back to `winsound` on Windows if Pygame audio fails |
| `pip install mediapipe` fails | Make sure you are using 64-bit Python 3.9 or newer |
| `Failed to build 'pygame'` | Uninstall the original package with `pip uninstall pygame` and install `pygame-ce` instead; it is a drop-in replacement. On Windows the program also works without it, using the built-in `winsound` |

## Limitations and future scope

Dark sunglasses hide the eyes, and very low light reduces accuracy. Future improvements could include head-pose estimation to detect nodding, an infrared camera for night driving, a trained CNN eye-state classifier, running on a Raspberry Pi or Jetson Nano inside a vehicle, SMS or GPS alerts to a family member or fleet manager through a GSM module, and a mobile-app version.
